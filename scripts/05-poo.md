# Lección 5 · Clases, objetos y encapsulación

## Una clase describe a un jugador

**Narración.** «La clase describe qué datos tiene un jugador. Ana y Luis son dos objetos diferentes que usan esa misma descripción».

**Pantalla.** Dibuja dos fichas. Une cada ficha con una llamada a `new Jugador(...)`. Señala dónde el constructor inicializa los datos.

## Protege el puntaje

Explica que `private` limita el acceso directo desde otras clases. Usa getters para leer los datos y el setter para cambiar el puntaje si es válido. Explica que `this.puntaje` es el atributo del objeto actual y `puntaje` es el parámetro.

## Pausa y reto

Pide crear otro jugador, cambiar su puntaje a 8 y luego probar -1. Comprueba que sigue en 8. Explica que el proyecto guardará varias fichas en un arreglo.
