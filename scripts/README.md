## Antes de publicar

- Grabar el editor en línea con texto grande, narración clara y anotaciones breves. Evitar logos del equipo, nombres y referencias a los autores en el video y el código.
- Mostrar la consola y dejar un momento para intentar cada reto antes de explicar la solución.
- Subir el video a YouTube como **no listado**. Colocar el enlace al editor con el código inicial precargado en la descripción y en el plan de curso.
- Abrir los dos enlaces en una ventana privada y probar que el código funciona sin instalar herramientas. Revisar el resultado desde un navegador con una pantalla pequeña.
